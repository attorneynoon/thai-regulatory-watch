# Regulatory Watch Implementation Plan

Goal: ship an independent Python 3.12 monitor, GRC RSS/JSON contracts and GitHub hosting for the full reconciled watch inventory.
Spec: ../specs/2026-09-19-thai-regulatory-watch-design.md, amended by ../../WORK_LOG.md.
Execution: current agent, authorized by the owner's instruction to build.

## Constraints and review focus

Public metadata only; review_status unreviewed; legal_effect Not assessed. No GRC writes. Preserve source identity and every event. Access errors retain last-good output. Test reversion IDs, source-local titles, blocked redirects, invalid state, and unsafe markup.

## Tasks

- [x] Registry and identity: create registry.py and models.py; validate URL schemes, names, source status, bounds and selectors. Test date uncertainty and identifier collisions.
- [x] State engine: create engine.py; consume source plus normalized records and emit immutable revision events. Test baseline/unchanged/change/reversion/failure retention through apply_observations.
- [x] Collection: create transport.py and adapters.py; fetch robots-aware bounded HTML/RSS/page sources. Test redirect policy, hostile XML, Thai dates, document signatures and attachment rotation.
- [x] Public outputs: create publish.py and schemas; build RSS, JSON, source coverage, complete current inventory and dashboard from retained state. Test parseability, deterministic bytes, escaping and contract consistency.
- [x] CLI and inventory: implement validate/collect/build/health/check; reconcile every registry entry and named monitoring scope into config/sources.yml. Unsupported sources remain pending with an explanation.
- [x] Automation and docs: CI on PR, serialized hourly collector, explicit Pages deployment in the same workflow, cloud/source onboarding and GRC consumer guide. Test permissions and publication artifacts.
- [x] Verification and release: Python 3.12 test suite, real-source bounded probes, representative item inspection, public-metadata review, GitHub push, Actions run and published-feed readback. Record actual limitations.

Release evidence and open source-qualification/cloud-environment steps: reports/VERIFICATION.md and docs/WORK_LOG.md. Completion means the independent producer is deployed, not that every inventory scope is operational.

Commands: python -m unittest discover -s tests -v; python -m regwatch validate; python -m regwatch build; python -m regwatch check; python -m regwatch collect --source SOURCE_ID; python -m regwatch health.
